# 🧠 Multi-Agent Research System

This project implements a **multi-agent pipeline** for automated research synthesis.  
Agents collaborate with external tools (Tavily API, BeautifulSoup) to fetch, parse, read, write, and critique research outputs, producing a polished final report.

---

## 🔄 Workflow Overview

1. **Research Topic Input**  
   - User provides a topic string (e.g., `"Impact of AI on Healthcare"`).

2. **Search Agent**  
   - Queries **Tavily API (Tool 1)** for live web search results.  
   - Results are saved for downstream use.

3. **Reader Agent**  
   - Consumes Tavily results.  
   - Passes them to **BeautifulSoup Scraper (Tool 2)** for parsing and content extraction.  
   - Parsed content is returned to the Reader Agent and saved.

4. **Writer Agent**  
   - Synthesizes structured draft (summary, insights, references) from Reader Agent’s saved results.

5. **Critic Agent**  
   - Reviews the Writer Agent’s draft.  
   - Provides corrections, ensures clarity, coherence, and factual accuracy.  
   - Produces the **final polished research output**.

├── src/                          # Source code
